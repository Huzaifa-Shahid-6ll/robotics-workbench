## [0.1.0 preview](https://github.com/Huzaifa-Shahid-6ll/robotics-workbench/releases/tag/v0.1.0)

- Local Windows x64 VS Code extension and companion for ordinary Arduino sketches.
- Saved-source compile diagnostics, explicit exact-artifact upload, and bounded serial capture and replay.
- Codex and OpenCode conversation, context inspection, and native source review.
- Parts and intended wiring, versioned document citations, run comparisons, and KiCad and CAD handoffs.
- Improved keyboard interaction, Agent draft preservation, native current-editor conflict diffs, and telemetry clock isolation.

The preview has passing local software, synthetic browser, and isolated installed-host checks. Full native accessibility, live provider, hardware, and supported-platform acceptance remain open.

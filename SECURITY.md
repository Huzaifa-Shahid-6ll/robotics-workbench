# Security policy

## Report privately

Use [Report a vulnerability](https://github.com/Huzaifa-Shahid-6ll/robotics-workbench/security/advisories/new). Include the affected version, relevant platform, steps to reproduce, observed impact, and a minimal example. Use synthetic artifacts where possible. Remove credentials, serial numbers, local paths, and personal project data.

The current preview is the focus for fixes. There is no guaranteed response window. The maintainer will use the private advisory thread to coordinate reproduction, remediation, and disclosure.

## Workbench boundaries

The extension coordinates local tooling and requires explicit hardware targets. It is not an operating-system sandbox. Suspected credential exposure, unauthorized file or device access, unexpected firmware mutation, or a bypass of operation confirmation belongs in a private report. Use the regular issue tracker for ordinary defects.

# Motion

Opening **Task details and actions** offsets its body by 2 CSS pixels and settles over 120 ms. Native `details` opens and closes immediately. The animation changes only presentation, and closing or disposing the view removes the effect. The shared sheet suppresses it for `prefers-reduced-motion` and `body.vscode-reduce-motion`.

The Agent harness checks the computed duration and both suppression paths. No animation drives an operation status, measurement, selection, or receipt. Hidden graphics and capture lifecycle remain separate existing behaviors and require their own evidence.

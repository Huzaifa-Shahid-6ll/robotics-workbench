# Approved reference map

The native VS Code shell remains the visual foundation. D42 supplies host color roles, host typography, compact spacing, small radii, and thin dividers. Cursor and Warp site-level styles were consulted for technical hierarchy. The project does not take their site colors, fonts, or marketing layouts.

Approved IDs below resolve through [the exact screen ledger](../../references/approved-screens.json). Refero returned metadata for all twelve IDs. The integrator inspected R01–R06 and R12 thumbnails. The telemetry and engineering workers inspected R07–R11 screenshots. These are references for layout and interaction, with the host theme supplying the implementation values.
